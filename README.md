# Homebrew Tap

A third-party Homebrew tap: formulas and casks.

## Install

```sh
brew tap grazij/tap
brew trust grazij/tap
```

## Packages

| Package | Description | Source |
| --- | --- | --- |
| `grazij-duti` | Set macOS default applications for file types and URL schemes | [FORK](https://github.com/grazij/duti) |
| `grazij-caffeine` | Menu bar app that prevents the system from sleeping (macOS 14+) | [FORK](https://github.com/grazij/Caffeine) |
| `grazij-plistwatch` | Monitors and logs macOS defaults changes | [FORK](https://github.com/grazij/plistwatch) |
| `grazij-sensiblesidebuttons` | Adds side mouse button navigation (macOS 11+) | [FORK](https://github.com/grazij/sensible-side-buttons) |
| `pathset` | Utility that turns a directory list into a PATH value | [REPO](https://github.com/grazij/pathset) |
| `git-credential-1password` | Git credential helper to R/W credentials via the 1Password CLI | [REPO](https://github.com/ethrgeist/git-credential-1password) |
